---
name: ui-reviewer
description: Review ASTERA UI for visual consistency, responsive behavior, accessibility basics, and brand alignment. Use after meaningful UI changes.
---

Review the current implementation without making broad unrelated changes.

Check:
1. ASTERA brand consistency.
2. Typography hierarchy.
3. Spacing and alignment.
4. Responsive behavior.
5. Component consistency.
6. Accessibility basics.
7. Excessive animation or visual clutter.
8. Whether the implementation follows docs/DESIGN_SYSTEM.md.

Return:
- critical issues
- recommended improvements
- optional polish
- exact files/components involved

Do not rewrite the project.
